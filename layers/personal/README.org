#+TITLE: personal layer

* Description
Personal Spacemacs private layer.  All non-trivial configuration is composed
of small topic modules under =modules/=.

* File layout
| File                    | Responsibility                                          |
|-------------------------+---------------------------------------------------------|
| =layers.el=             | Declare official Spacemacs layers (languages, tools)    |
| =packages.el=           | Extra packages (currently empty; extras live in init.el =dotspacemacs-additional-packages=) |
| =config.el=             | Aggregator: =require= topic modules in load order       |
| =funcs.el=              | Reusable helper functions                               |
| =keybindings.el=        | Global key bindings (Emacs style)                       |
| =modules/personal-mac.el=     | macOS: =exec-path-from-shell=, TRAMP                    |
| =modules/personal-lsp.el=     | lsp-mode / lsp-ui / gopls / projectile / protobuf hook  |
| =modules/personal-ui.el=      | doom-modeline, fonts, whitespace, dired, yas, indent    |
| =modules/personal-writing.el= | markdown, org, plantuml, ox-latex                       |
| =modules/personal-ai.el=      | agent-shell (Claude Code / Codex / Gemini)              |

* Adding a new topic
1. Create =modules/personal-<topic>.el= ending with =(provide 'personal-<topic>)=.
2. Append =(require 'personal-<topic>)= to =config.el= in the desired load order.
3. Restart Emacs.  No changes to =init.el= are needed.

The load order matters:
=mac= → =lsp= → =ui= → =writing= → =ai=.  Shell PATH must be inherited before
LSP servers spawn; UI runs after LSP so mode-line reflects LSP state; AI is
last and defensively deferred so its dependencies never block startup.

* Install
Add =personal= to =dotspacemacs-configuration-layers= in your =init.el=.

External dependencies (macOS, one-off):

#+BEGIN_SRC sh
# Icon fonts for doom-modeline
M-x all-the-icons-install-fonts

# AI agent CLIs (only needed to actually use the AI layer)
npm i -g @zed-industries/claude-code-acp
npm i -g @agentclientprotocol/codex-acp
# Gemini CLI: install per Google docs, ensure --experimental-acp works
#+END_SRC

* Key bindings
| Key Binding | Description                                    |
|-------------+------------------------------------------------|
| =C-c p=     | Copy absolute file path with line number       |
| =C-c P=     | Copy project-relative file path with line      |
| =C-c w=     | Copy current line to kill ring                 |
| =C-S-f=     | =counsel-rg= (project-wide ripgrep search)     |
| =C-c f=     | =counsel-fzf= (project file-name search)       |
| =C-;=       | ace-jump-mode                                  |
| =C-x SPC=   | ace-jump-mode pop mark                         |
| =SPC a a=   | agent-shell (choose agent)                     |
| =SPC a c=   | Start Claude Code agent                        |
| =SPC a x=   | Start Codex agent                              |
| =SPC a g=   | Start Gemini agent                             |
